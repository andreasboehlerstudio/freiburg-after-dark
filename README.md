# Freiburg After Dark

Version 1.7.0 — ein gezeichnetes 2D-Beat-’em-up durch das nächtliche Freiburg, mit einem Spieler und automatisch kämpfendem Sidekick.

Im Browser öffnen, „Spiel starten“ wählen, Hauptfigur und Sidekick auswählen und „Nacht starten“ drücken. Auf dem Startbildschirm läuft Musik als Loop; falls der Browser zunächst stumm bleibt, „Musik aktivieren“ anklicken. Beim Spielstart wird zur Levelmusik überblendet. In den Einstellungen lassen sich Musik, Effekte und Kampflaute getrennt regeln.

## Steuerung

| Aktion | Tastatur | Standard-Gamepad |
|---|---|---|
| Bewegen | WASD / Pfeile | Linker Stick / Steuerkreuz |
| Schlag / Schläger benutzen | J | X |
| Schwerer Tritt | K | Y |
| Springen | Leertaste | A |
| Sprungtritt | Im Sprung J oder K | Im Sprung X oder Y |
| Gegenstand aufnehmen / werfen | E drücken | LB drücken |
| Partner schneller aufhelfen | In seiner Nähe E halten | LB halten |
| Spezialattacke | L | RB |
| Ausweichen | Umschalt | B |
| Pause | Esc | Start |
| Vollbild | F | Bildschirm-Schaltfläche |

Ein Baseballschläger hält sechs erfolgreiche Schläge; J wirft ein getragenes Fahrrad. E wirft beide Gegenstandsarten. In der Nähe eines gestürzten Partners hat das Aufhelfen Vorrang.

## Die Nacht

Sechs lange Levels: Kaiser-Joseph-Straße, Stühlinger, Stühlinger Park, Haslach / Weingarten, Wiehre / Alter Wiehrebahnhof und das Finale im Bermuda-Dreieck am Martinstor. Nach jeder geräumten Arena rechts weitergehen. Die Mähne bewacht die letzte Tür. Nach jedem Levelboss erscheint eine animierte Siegesfeier; „Weiter“ führt ins nächste Viertel.

Gegner treffen zeitversetzt aus verschiedenen Richtungen ein. Die Besetzung reicht von schmächtigen schnellen Figuren bis zu schweren Muskelpaketen; sitzende Protestfiguren greifen nicht an. Parkende Kleinwagen und Luxuscoupés lassen sich mit Angriffen und geworfenen Gegenständen zertrümmern.

Das Spiel und seine Gegnerrollen sind fiktional. Die Freiburger Schauplätze sind als Arcade-Kulissen interpretiert. Fortschritt und Einstellungen bleiben im Browser auf diesem Gerät. Desktop-Steuerung; der Sidekick wird von der KI gespielt.

Die Schrift Anton wird mit ihrer OFL-Lizenz ausgeliefert; siehe assets/fonts/OFL-Anton.txt.
